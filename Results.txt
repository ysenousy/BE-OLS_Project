Results
=======

Step 1: TTL Metadata Extraction
-------------------------------

119 ontology TTL files were processed.

117/119 parsed successfully (98.3% success rate).

2 files failed to parse because of source-file issues:
- sao.ttl: unbound xs: prefix in the source TTL
- th-building.ttl: maximum recursion depth exceeded while parsing

Metadata quality:
- Mean completeness: 65.6% across all ontologies
- 71 ontologies include license metadata
- 86 ontologies include version metadata
- 72 ontologies include creator metadata

Ontology structure averages:
- Mean classes per ontology: 120
- Mean properties per ontology: 62
- Mean axioms/triples per ontology: 1,982
- Mean annotation coverage: 69.8%
- Mean comment coverage: 60.0%


Step 2: Academic Paper Search
-----------------------------

Current Step 2 uses OpenAlex search with ontology-specific profiles from
ontology_search_profiles.json. Semantic Scholar and OpenAIRE are not used in
the current pipeline.

The final paper output was cleaned using profile-level filters for ambiguous
ontology names and generic domains. The output keeps papers classified as:
- exact_ontology
- ontology_family
- reuse_application

Paper search output:
- Ontologies searched: 119
- Total paper results kept: 120
- Ontologies with >=1 paper result: 44
- Ontologies with 0 paper results: 75
- Mean results per ontology with results: 2.7
- Mean results per ontology overall: 1.0

Match type distribution:
- exact_ontology: 107
- ontology_family: 2
- reuse_application: 11

Paper metrics:
- Mean title/query overlap: 0.2002
- Mean abstract/query overlap: 0.0333
- Mean citation count: 36.7
- Median paper year: 2021
- Ontologies with direct DOI hit: 1/119


Step 3: Web Search
------------------

Current Step 3 seeds official namespace/repository URLs from ontology metadata,
then uses DuckDuckGo search profiles to collect additional ontology-related web
pages. Results are deduplicated, filtered, scored, and classified by result type.

Web search output:
- Ontologies searched: 119
- Total web results kept: 379
- Ontologies with >=1 web result: 115
- Ontologies with 0 web results: 4
- Mean results per ontology with results: 3.3
- Mean results per ontology overall: 3.2
- Zero-result web ontologies: ph.ttl, sao.ttl, th-building.ttl, wgs84.ttl

Web result type distribution:
- official_namespace: 55
- github_repo: 26
- paper: 62
- documentation: 102
- other: 134

Step 3 cleanup notes:
- Official namespace/repository URLs are seeded from ontology metadata.
- DuckDuckGo results are filtered to remove generic/noisy sources such as
  YouTube, LinkedIn, Wikipedia, BE-OLS catalog pages, and unrelated acronym or
  company-directory pages.
- Boilerplate snippets from generated ontology documentation are replaced or
  removed when possible.


Step 4: Dataset Consolidation
-----------------------------

Step 4 merges ontology metadata, metadata metrics, academic paper results,
web results, and per-ontology search metrics into one consolidated dataset.

Consolidated output:
- Dataset rows: 119
- Parse success rate: 98.3%
- Mean metadata completeness: 65.6%
- Ontologies with >=1 paper result: 37.0%
- Ontologies with >=1 web result: 96.6%
- Total paper results: 120
- Total web results: 379
- Mean classes per ontology: 120.3
- Mean properties per ontology: 61.6
